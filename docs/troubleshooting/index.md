# 排障指南

> 🚧 本章节编写中，以下为规划大纲。

## 日志

规划内容：

- 日志位置与级别调整
- 请求日志字段解读
- 通过 Request ID 检索一次调用的全链路记录

## Request ID 全链路追踪

一次请求的 Request ID 贯穿：客户端响应头 → 网关请求日志 → 上游转发记录 → 计费流水。规划一个端到端排查实例。

## 常见报错速查表

| 现象 | 可能原因 | 处理方式 |
|------|---------|---------|
| 启动即退出 | 数据库 / Redis 连不上 | 检查连接配置与网络 |
| 上游 502 / 504 | 渠道地址或超时设置 | 核对渠道配置、调整超时 |
| 流式响应中断 | 反代缓冲 / 超时 | 见[Nginx 反向代理](/deploy/nginx) |
| 额度误判 | 并发预扣视图延迟 | 等待结算或查计费流水 |
