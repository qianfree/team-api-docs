# 常见问题

> 🚧 本章节编写中。以下为规划的问题分类，欢迎在 [GitHub Issues](https://github.com/qianfree/team-api/issues) 提问。

## 部署相关

- Docker 启动后无法访问，如何排查？
- 数据库迁移失败 / 卡住怎么办？
- 如何从旧版本升级？会不会丢数据？

## 渠道相关

- 渠道测试通过但正式请求报错？
- 为什么请求没有走优先级最高的渠道？
- 如何配置渠道权重与故障转移？

## 计费相关

- 流式响应的 Token 用量如何统计？
- 预扣和实际结算金额为什么有差额？
- 套餐额度与钱包余额的扣费顺序？

## 账号与权限

- 忘记管理员密码怎么办？
- 租户成员角色有哪些权限区别？

## API 调用相关

- 报 401 / 403 是什么原因？
- 报 429 限额错误如何定位是哪一层额度不足？
- 图片 / 语音 / 实时接口有什么特殊要求？
