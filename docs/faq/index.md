## 系统配置相关

### 系统添加模型的步骤是怎么样的？

1. **新增模型**：在**管理后台 → 模型配置**新增模型，填写模型标识（即 API 请求中的 `model` 参数，创建后不可修改）、分类、上下文 / 输出上限等参数，可点击「拉取官方数据」自动填充；
2. **渠道承接**：新增渠道或选择已有渠道，进入渠道详情，在「模型能力」中添加该模型（上游模型名不同时需填写映射），添加完成后到「测试」Tab 发一条真实请求，验证模型真实可用（当前仅支持文本对话类模型）；
3. **授权**：将新模型加入特定[模型分组](/guide/admin/model-groups)，或授权给指定租户；
4. **设置价格**：在模型列表点击「定价」设置基准价——**没有价格的模型无法调用**。

详细操作见[模型配置](/guide/admin/models)与[渠道配置](/guide/admin/channels)。

### 如何设置套餐？

系统当前仅支持**按量付费**：用户充值进入钱包余额，按实际用量实时扣费，不支持套餐订阅。

模型定价层面支持按量 / 按次 / 阶梯三种计费模式，见[模型定价](/guide/admin/models#模型定价)。

### 用户如何付款？

1. 管理员在系统中配置[易支付](#什么是易支付)；
2. 用户在租户控制台的**钱包充值页**选择面额、完成支付，到账后余额实时增加。

充值面额、折扣、汇率、支付说明等全局参数见[支付配置](/config/settings-payment)。

### 什么是易支付？

易支付（EPay）是国内广泛使用的一套**聚合支付接口协议**及配套自建系统（最早源于开源项目「彩虹易支付」）。平台方部署易支付系统后，统一对接支付宝、微信支付等收款渠道；商户侧只需对接易支付一套接口即可收款，无需逐个申请支付宝 / 微信官方商户号。

对接流程：

1. 用户发起充值，系统按易支付协议提交订单（`submit.php` 接口），跳转到收银台；
2. 用户扫码 / 完成支付；
3. 易支付平台通过**异步通知**（notify_url）回调系统确认到账，钱包余额随即入账。

对接时通常需要填入**网关地址、商户 ID（pid）、商户密钥**三类参数。

::: warning 谨慎选择服务商
易支付平台多为第三方「四方支付」，资质与资金安全参差不齐，存在掉单、跑路与合规风险。请选择可靠的服务商，大额或长期业务建议使用官方支付渠道。
:::
