# 租户管理

**管理后台 → 租户管理**

租户（组织）是平台对外服务的单位：授权、计费、成员、审计都以租户为边界。租户管理模块承担租户的完整生命周期——**创建 → 授权 → 开通使用 → 运营管控**，由四部分组成：

| 页面 | 职责 |
|---|---|
| 租户列表 | 创建租户、编辑配额、状态筛选与导出 |
| 租户详情 | 基本信息、模型分配、钱包与计费、交易记录 |
| 租户级别 | 配置等级体系，基于累计充值自动升级 |
| 成员列表 | 跨租户的成员账号运维（禁用 / 解锁 / 重置密码） |

```mermaid
flowchart LR
    C["① 创建租户<br/>管理员账号 + 租户代码"] --> I["自动初始化<br/>LV1 · 美元钱包 · 默认分组"]
    I --> A["② 授权模型<br/>分组授权 / 独立分配"]
    A --> U["③ 开通使用<br/>充值入账 · 成员邀请"]
    U --> O["④ 持续运营<br/>等级升级 · 状态管控"]
```

::: tip 与租户控制台的分工
本模块是**平台运营方**的视角；租户内部的日常管理（邀请成员、成员额度、项目组织等）由租户所有者 / 管理员在[租户控制台](/guide/tenant/)完成，两套账号体系相互独立。
:::

## 创建租户

租户列表页点击**创建租户**，一个表单完成租户与其管理员账号的创建：

| 字段 | 说明 |
|---|---|
| 租户名称 | 组织展示名，最短 2 个字符，最长按显示宽度 16 计（汉字占 2、字母数字占 1） |
| 租户代码 | 3–30 位，仅小写字母、数字、中划线且以字母或数字开头结尾，全局唯一，**创建后不可修改** |
| 管理员用户名 | 3–50 位，仅英文字母和数字，不能为纯数字 |
| 管理员邮箱 | 必填，平台内唯一（创建后管理员可直接用邮箱登录） |
| 管理员密码 | 8–64 位，必须同时包含字母和数字 |
| 最大成员数 | 选填，**留空跟随等级配置**；填写则覆盖等级（列表中标注「自定义」） |
| 并发上限 | 选填，留空跟随等级配置，0 表示不限 |

创建成功后系统在同一个事务里自动完成初始化：

1. **创建所有者账号** —— 填写的管理员即租户所有者（owner 角色），名称与邮箱不可与其他租户的成员重复；
2. **开通美元钱包** —— 余额为 0，余额预警默认关闭；
3. **关联默认分组** —— 自动关联全部「启用中且标记为默认」的[模型分组](/guide/admin/model-groups)，租户立即可用标准模型目录。

::: tip 租户代码即组织代码
租户代码就是租户控制台的组织代码：成员使用 `用户名@租户代码` 登录控制台。管理后台创建的租户代码在创建时即已确定，租户无需再自行设置。
:::

::: warning 默认分组前提
若平台尚未配置任何「启用中且标记为默认」的分组，新租户将拿不到任何模型——请先完成[分组配置](/guide/admin/model-groups)再批量创建租户。
:::

## 租户列表

列表支持按**状态**（正常 / 暂停 / 已关闭）筛选、按租户名 / 代码搜索，并可导出 CSV / Excel 报表。

| 列 | 说明 |
|---|---|
| 状态 | 正常 / 暂停 / 已关闭 |
| 所有者 | 创建租户时的管理员账号 |
| 成员 / 成员上限 | 当前成员数与生效上限，自定义值标注「(自定义)」 |
| 并发上限 | 生效的租户总并发上限，自定义值标注「(自定义)」 |
| 等级 | 等级名称标签；等级价格乘数小于 1 时附加折扣标签（如 `15%折扣`） |
| 钱包余额(美元) | 该租户钱包总余额 |

行操作：**详情**进入租户详情，**编辑**修改租户配置。

### 编辑租户

| 字段 | 说明 |
|---|---|
| 租户名称 | 展示名（租户代码不可修改） |
| 租户等级 | 调整后，**未自定义**的成员数 / 并发上限自动跟随新等级配置，已自定义的字段保持不变 |
| 最大成员数 / 并发上限 | 清空即恢复「跟随等级」 |

生效优先级：**租户自定义值 > 等级配置**；两者都未设置时，成员数上限默认 10、并发不限。

## 租户状态

状态管理在租户详情页头部操作：

| 状态 | 说明 |
|---|---|
| 正常（active） | 正常使用 |
| 暂停（suspended） | 暂停后该租户下**所有成员**无法使用服务，可随时恢复 |
| 已关闭（closed） | **不可逆**操作，关闭后不再提供状态变更入口 |

::: warning
「关闭」不可逆。对暂时不活跃的租户优先使用「暂停」，保留恢复能力；确需关闭时先与租户确认数据与余额处理。
:::

## 租户详情

详情页分四个标签页：

### 基本信息

租户的 ID、代码、状态、所有者、成员数 / 上限、钱包余额、等级与创建时间一览，同页提供编辑表单（同[编辑租户](#编辑租户)）。

### 模型分配

分组授权与独立模型分配都在此完成，包括逐模型设置折扣、自定义价与并发上限；顶部「查看可用模型」汇总该租户最终可用的模型清单及其来源（分组 / 独立分配），是排查「租户为什么（不）能用某模型」的第一入口。详见[分组配置 → 分配给租户](/guide/admin/model-groups#分配给租户)。

### 钱包与计费

| 功能 | 说明 |
|---|---|
| 钱包信息 | 总余额、冻结余额、可用余额（总余额减冻结，即扣减上限） |
| 调整余额 | 正数增加、负数扣减（不超过可用余额），用于运营补偿与余额纠错，建议填写说明便于对账 |
| 线下入账 | 线下人民币转账入账：按平台汇率换算为美元，可选填转账流水号用于防重复入账，金额**计入累计充值**、影响租户等级 |
| 预警阈值 | 可用余额低于阈值时触发预警通知，设为 0 关闭 |
| 冻结明细 | 逐笔查看请求预扣冻结（正常情况下请求结束自动释放，异常滞留最长约 2 小时自动清理），支持手动释放与一键释放 |

::: tip 冻结释放
释放只是把金额从冻结退回可用余额，不改变总余额；操作需 `billing:refund` 权限并填写原因。冻结不足 10 分钟的请求可能仍在进行中，默认跳过、需勾选强制释放——释放后该请求将失去超扣保护。
:::

### 交易记录

该租户的全部交易流水（充值、消费、调整），与[钱包与计费](#钱包与计费)中的余额变动一一对应。

## 租户级别

**管理后台 → 租户管理 → 租户级别**

等级体系把「充值规模」映射为「资源配额 + 价格优惠」，基于钱包**累计充值**自动升级、仅升不降：

| 字段 | 说明 |
|---|---|
| 等级号 | 1–99，**创建后不可修改**；LV1 为初始等级，不可删除 |
| 等级名称 | 如「LV2 白银用户」 |
| 累计充值阈值(USD) | 钱包累计充值达到该值自动升入此等级，按阈值从高到低取满足的最高等级 |
| 最大成员数 | 该等级默认成员数上限，0 表示不限 |
| 最大并发数 | 该等级默认并发上限，0 表示不限 |
| 价格乘数 | 0.01–2，参与结算：`结算价 = 基准价 × 等级乘数`（再叠加模型级折扣 / 自定义价），0.9 即九折 |
| 排序权重 | 展示排序 |

自动升级规则：

- 触发时机是**充值入账**（在线支付、兑换码、线下入账均计入累计充值）——升级只看累计充值，消费与退款不降级；
- 升级时等级号必定更新；成员数 / 并发上限按**仅升不降**同步（新等级配置更优才覆盖，未自定义的字段直接跟随新等级）；
- 等级变化后价格缓存自动失效，新乘数立即生效。

::: tip
LV1 的价格乘数恒按原价结算，配置其他乘数不会生效——价格优惠从 LV2 起设置。
:::

## 成员列表

**管理后台 → 租户管理 → 成员列表**

平台视角的成员账号运维页，汇聚**全部租户**的成员：按所属租户（可搜索选择）、状态（正常 / 禁用 / 锁定）、角色（Owner / Admin / Member）筛选，按用户名 / 邮箱搜索，支持导出 CSV / Excel。

与[租户控制台的成员管理](/guide/tenant/team)分工不同：控制台由组织管理员负责邀请与授权（角色、成员额度、可用模型）；本页面负责平台侧的账号管控，不涉及额度与模型授权。

### 添加成员

为某个租户直接代建账号：选择所属租户（仅正常状态）、填写用户名 / 邮箱 / 密码（8–64 位，含字母和数字）、显示名（选填），角色可选 **Admin / Member**——Owner 只在创建租户时产生，不能手动指定。创建后成员用 `用户名@租户代码` 登录。

### 成员操作

| 操作 | 说明 |
|---|---|
| 禁用 / 启用 | 禁用后成员无法登录使用平台，可随时启用恢复 |
| 重置密码 | 系统生成新的随机密码，**仅在弹窗中展示一次**，请当场告知成员 |
| 解锁 | 成员因多次登录失败被临时锁定时手动解锁 |

## 常见管理流程

- **大客户开通**：创建租户 → [模型分配](#模型分配)中按协议配置分组与独立价 → 线下入账 → 把管理员账号交付客户，客户自行邀请成员；
- **投诉余额不对**：租户详情 → 钱包与计费 → 核对[冻结明细](#钱包与计费)与交易记录 → 必要时调整余额并注明原因；
- **欠费 / 违规租户**：先「暂停」停止服务，处理完毕后恢复或关闭；
- **成员账号出问题**：成员列表按租户 / 用户名定位 → 禁用、解锁或重置密码。
