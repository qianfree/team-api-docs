# 请求审计日志

**租户控制台 → AI 服务 → 请求审计日志**

请求审计日志记录组织内**每一次 API 调用的输入与输出**：谁、在什么时间、用什么客户端、发了什么、模型回了什么、耗时多久。面向合规审查、敏感内容追溯与用量争议核对，仅所有者与管理员可见。

记录范围由「设置 → 审计设置」中的**审计级别**决定：

| 审计级别 | 记录内容 |
|---|---|
| 完整记录 | 请求体与响应体的完整原文 |
| 全量文本 | 思考过程与回答内容（不含原始 SSE 数据） |
| 脱敏记录（默认） | 请求与响应均记录，敏感字段脱敏 |
| 仅记录提问 | 只记录用户输入，不记录模型回复 |
| 关闭 | 不记录任何审计日志 |

::: tip 与用量日志的分工
[用量日志]面向**计费**（Token、费用、模型、渠道），人人可见；请求审计日志面向**内容**（输入输出原文），仅管理者可见、保留策略独立（见平台的[审计配置](/config/settings-audit)），大数据量场景可写入独立数据库。
:::

## 检索

默认查询当天，支持组合筛选：

- **时间范围** —— 起止日期时间；
- **用户名 / 项目** —— 定位到某成员或某项目的调用；
- **Request ID / Task ID** —— 精确到一次请求或一个异步任务（可从用量日志、客户端响应头中拿到 ID 后跳转过来）；
- **请求路径** —— 如 `/v1/chat/completions`；
- **状态码** —— 如只看 4xx / 5xx。

列表展示：Request ID、用户 / 项目、方法与路径、状态码、客户端（User-Agent 解析出的浏览器 / 系统）、延迟、首 Token 用时（按 <500ms / <1500ms 分档着色）、审计级别、异步任务状态、发生时间。

## 详情

点击任意一行查看完整审计记录：

- **元信息** —— Request ID、时间、方法 / 路径、状态码、延迟、首 Token 用时、客户端 IP、审计级别、User-Agent；
- **异步任务** —— 图像 / 视频类异步调用的任务 ID、任务状态（已提交 / 排队中 / 处理中 / 成功 / 失败 / 超时）、完成时间与上游响应；
- **请求体（输入）** 与 **响应体（输出）** —— 按 JSON 格式化展示。

若详情中没有输入输出内容，说明当前审计级别未记录（如「仅记录提问」下无响应体，或该请求发生在级别调整之前）。

## 典型用法

- **合规审查** —— 定期按时间范围导出审查成员与模型的交互内容；
- **争议核对** —— 业务方反馈「这次回复不对 / 计费不对」时，用 Request ID 调出完整输入输出与耗时核对；
- **泄漏溯源** —— 结合客户端 IP 与 User-Agent，确认某把 Key 是否被第三方盗用。
