# 团队管理

**租户控制台 → 成员管理**

团队管理面向组织所有者与管理员，覆盖成员的完整生命周期：**邀请 / 创建 → 授权（角色、额度、模型）→ 监控用量 → 移除**。组织内每位成员的消费计入组织钱包，成员额度是控制个人用量的主要手段。

> 团队功能需要先在「组织设置」中设置组织代码启用；个人模式下本页显示引导提示。

## 添加成员的三种方式

### ① 邀请链接（推荐）

「邀请成员」生成一个可分发的注册链接：

| 配置 | 选项 |
|---|---|
| 角色 | 成员 / 管理员（加入后可再调整） |
| 有效期 | 1 / 3 / 7 / 14 / 30 天 |
| 使用次数 | 不限 / 1 / 5 / 10 / 20 / 50 次 |

收到链接的人在**加入组织**页面完成注册即自动加入并带上预设角色。链接状态可在**邀请记录**中查看（已使用次数、过期时间、创建者），未过期的链接可随时复制或**撤销**。

### ② 直接创建

为成员指定用户名、初始密码（至少 8 位，含字母和数字）、邮箱（选填）、显示名与角色。适合为不熟悉注册流程的同事代建账号——创建后把用户名和初始密码告知对方，成员用 `用户名@组织代码` 登录。

### ③ CSV 批量导入

先下载**导入模板**，按格式填写后上传：

```csv
username,display_name,email,role,models
alice,Alice Chen,alice@example.com,member,
bob,Bob Wang,bob@example.com,admin,gpt-4o;claude-sonnet-4-5
```

- `models` 列用分号分隔模型名，可限定该成员的可用模型，留空表示不限制；
- 单次最多 500 条，导入结果逐行反馈成功 / 失败 / 跳过及原因（如用户名重复）。

## 成员列表

按用户名 / 邮箱 / 显示名搜索，支持导出 CSV / Excel。关键列：

| 列 | 说明 |
|---|---|
| 角色 | 所有者 / 管理员 / 成员 |
| 状态 | 已激活 / 已邀请 / 已禁用 |
| 额度限制 | 不限制，或金额 + 周期（按天 / 按周 / 按月） |
| 可用模型 | 不限，或已授权的模型数量 |
| 本月消费 | 该成员本月产生的 USD 消费 |

点击成员进入详情页。

## 成员详情

### 用量概览

今日请求数、本月请求数、本月 Token 用量（输入 / 输出分列）、本月消费、API Key 数量五张统计卡，成员的成本一目了然。

### 额度限制

三种模式：

| 模式 | 说明 |
|---|---|
| 不限制 | 不设成员级上限，仅受组织钱包与套餐约束 |
| 总额度 | 设一个累计消费上限（USD），用完即止 |
| 周期性 | 按天 / 周 / 月重置的周期额度，卡片展示已用百分比与下次重置时间 |

请求在转发前校验成员额度，不足即拒绝（见[五层额度模型](/guide/quota)），不会消耗上游成本。

### 可用模型

默认**不限制**（可使用组织的全部可用模型）。勾选授权后，成员只能调用清单内的模型——新员工只开低成本模型、资深成员开放旗舰模型，是常见的分级做法。成员侧的体现：个人 Key 的模型范围在此基础上进一步收紧。

### 其他操作

- **调整角色** —— 在管理员 / 成员之间切换（所有者角色不可在此变更）；
- **重置密码** —— 为成员设置新密码；
- **解除锁定** —— 成员因多次登录失败等被临时锁定时手动解锁；
- **移除** —— 将成员移出组织。

## 常见管理流程

- **新成员入职**：邀请链接加入 → 按需设置[额度限制](#额度限制)（如按月 $20）→ 需要时收紧可用模型 → 成员自助创建[个人 Key](/guide/tenant/api-keys)；
- **用量异常**：成员列表按「本月消费」定位 → 详情页看用量概览 → 必要时收紧额度或禁用其 Key；
- **人员离职**：先移除成员（其名下 Key 一并失效），再按需归档其[项目](/guide/tenant/projects)。
