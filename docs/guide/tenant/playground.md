# 在线体验

**租户控制台 → 在线体验（API Playground）**

在线体验（Playground）是内置的模型调试工作台，覆盖**对话、图像、视频、语音、嵌入、重排**六类模型。无需写代码即可验证「这个模型在我的 Key 下能不能用、效果如何、参数怎么调」，适合选型评估与问题复现。

![租户控制台 — 在线 Playground](/images/tenant_playground_chat.png)

::: tip 计费与正式调用
Playground 使用真实的 API Key 走完整网关链路——正常计费、正常记录[用量日志](/guide/tenant/)与[请求审计日志](/guide/tenant/request-audit-logs)。它面向快速验证，各模型只暴露最常用的参数；正式接入应用请使用 [API 文档](/api/overview)。
:::

## 开始之前

页面右上角选择一把 **API Key**，左侧的模型列表随之切换为**该 Key 可调用的模型**——Key 的模型范围（见 [API Key 管理](/guide/tenant/api-keys)）在这里直接生效。没有可用 Key 时按提示先去创建。

切换下方分类标签进入对应能力：

| 标签 | 能力 | 主要参数 |
|---|---|---|
| 对话 | 多轮聊天、流式输出 | 模型、Temperature（0–2）、Max Tokens、System Prompt、流式开关；视觉模型可设图片宽高比 / 分辨率 |
| 图像 | 文生图 | 模型、提示词、自定义参数（键值对）；结果支持放大与下载 |
| 视频 | 文生视频（异步任务） | 模型、提示词、分辨率（480p / 720p / 1080p，横竖屏）、时长（秒） |
| 语音 | 文字转语音 | 模型、文本、音色、输出格式；结果在线试听 |
| 嵌入 | 文本向量化 | 模型、输入文本、维度（可选）；返回向量结果 |
| 重排 | 相关性重排序 | 模型、查询文本、文档列表（每行一个）、Top N；返回相关度得分排序 |

## 对话调试

最常用的标签：

1. 选模型，调 Temperature / Max Tokens，需要时写 System Prompt；
2. 保持**流式响应**开启可实时看到逐字输出（关闭则等待完整响应一次返回）；
3. 对话上下文连续保留，可清空重新开始。

流式输出同时是检验网关 SSE 链路的好方法——若这里流式正常而你的应用异常，问题多半在客户端或中间代理（见[Nginx 缓冲配置](/deploy/nginx)）。

## 图像 / 视频（异步任务）

图像生成走同步或异步取决于厂商与平台配置；视频生成均为**异步任务**——提交后进入任务队列，页面轮询展示状态（排队中 → 处理中 → 成功 / 失败 / 超时），完成后在线预览或下载。任务明细也可在「任务日志」与[请求审计日志](/guide/tenant/request-audit-logs#详情)中回查。

## 常见用途

- **接入前验证** —— 新 Key 创建后先在这里跑一条对话，确认模型范围与额度正常；
- **模型选型** —— 同一提示词切换多个模型对比效果与速度（首 Token 用时在审计日志中可查）；
- **参数试错** —— Temperature、分辨率、音色等先在这里试，合适后再写进应用代码；
- **问题复现** —— 用户反馈异常时，用同样的输入在 Playground 重放，配合 Request ID 定位。
