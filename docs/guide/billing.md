# 计费与对账

> 🚧 本章节编写中，以下为规划大纲。

## 计费流程

`预扣 → 转发 → 结算 → 退款` 四阶段：

```mermaid
flowchart LR
    A[预扣估算额度] --> B[转发上游]
    B --> C[按实际用量结算]
    C --> D[退还未用差额]
```

- **预扣**：请求进入时按最大可能用量预估并冻结额度
- **转发**：调用上游渠道
- **结算**：拿到上游真实 usage 后按模型倍率计价
- **退款**：预扣与结算差额即时退回

并发安全由 Redis 原子操作保证。
