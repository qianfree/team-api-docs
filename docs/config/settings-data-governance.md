# 数据治理

**管理后台 → 系统设置 → 数据治理**

各类数据（日志、临时数据、导出文件、图片）的**保留周期**——后台定时任务按这些天数自动清理过期数据，控制数据库与存储的无限增长。

## 日志保留

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `data_retention_api_logs_days` API 调用日志保留天数 | `90` | 调用明细 / 用量日志的保留期（7–3650 天），过期由定时任务删除 |
| `data_retention_operation_logs_days` 操作日志保留天数 | `365` | 管理与租户端操作审计日志的保留期（30–3650 天） |
| `data_retention_temp_data_days` 临时数据保留天数 | `1` | 中间态 / 临时数据的保留期（1–30 天） |

::: tip 保留期 ≠ 审计级别
这里控制的是**存多久**；记录多少由[审计配置](/config/settings-audit)的级别决定。想要更长追溯期，先确认磁盘容量（调用日志含请求响应体，量大）。
:::

::: warning 与审计配置页的关系
[审计配置](/config/settings-audit)页中的「审计日志 / 操作日志保留天数」为预留项，**实际清理以本页两项为准**。
:::

## 数据导出

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `data_export_expiry_days` 导出文件保留天数 | `7` | 数据导出任务生成文件的保留期（1–30 天），过期自动删除 |
| `data_deletion_completion_days` GDPR 删除请求完成天数 | `30` | 预留项：注销 / 删除请求的承诺完成时限，当前版本未接入 |

## 文件保留

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `file_retention_enabled` 启用文件保留期检查 | 开 | 文件保留期清理任务的总开关 |

::: tip AI 图片的保留天数在「文件管理」页
AI 生成图片转存后的清理天数（`file_image_retention_days`，0 = 不清理）不在本页，在**管理后台 → 系统管理 → 文件管理**页面设置。转存图片默认 0（永久保留），存储成本敏感时可设为 7–30 天（链接本身约 24 小时过期，过期链接即使文件还在也无法访问）。
:::

## 容量规划参考

| 数据类型 | 增长量级 | 建议 |
|---|---|---|
| API 调用日志 | 每次调用一条（含内容体） | 90 天起步，磁盘吃紧时下调或调低[审计级别](/config/settings-audit) |
| 操作日志 | 每次管理操作一条 | 365 天合规够用 |
| 转存图片 | 每张生成图一份对象存储文件 | 按生成量估算，或开启图片保留期清理 |
| 数据导出文件 | 每次导出一份 | 默认 7 天即可 |
