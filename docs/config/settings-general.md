# 基础配置

**管理后台 → 系统设置 → 基础配置**

站点身份、注册策略与维护模式。全新安装后建议首先检查本页。

## 基本信息

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `site_name` 站点名称 | `Team-API` | 显示在浏览器标题和系统发出的邮件中，对外可见 |
| `site_description` 站点描述 | 空 | 站点一句话简介，供前端展示使用 |
| `tenant_console_url` 租户控制台地址 | 空 | 租户控制台的完整 URL（如 `https://console.example.com`），用于生成**租户邀请链接**等跳转地址 |
| `pricing_time_timezone` 计费时区 | `Asia/Shanghai` | 模型**时段定价**（峰谷 / 促销价）按此时区解释，IANA 时区名。改错会导致高峰时段计费错档 |

::: tip
`tenant_console_url` 未配置时，邀请链接等功能可能拼出错误域名。管理后台与租户控制台分开部署（不同域名）时**必须配置**。
:::

## 注册设置

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `register_enabled` 开放注册 | 开 | 总开关：关闭后租户端不再提供自主注册，只能由管理员创建租户 |
| `register_email_verification` 注册邮箱验证 | 关 | 开启后注册需输入**邮箱验证码**（依赖[邮件配置](/config/settings-email)已配好）；关闭时使用滑块验证 |
| `register_ip_limit_per_hour` IP 每小时注册限制 | `50` | 同一 IP 每小时最多注册次数，`0` 不限制，范围 0–200 |
| `register_ip_limit_per_day` IP 每天注册限制 | `500` | 同一 IP 每天最多注册次数，`0` 不限制，范围 0–1000 |
| `register_global_limit_per_minute` 全局每分钟注册限制 | `50` | 全系统每分钟最多注册次数（防机器人批量注册的总闸），`0` 不限制 |

三个限流维度各自独立计数，防刷策略建议**同时保留 IP 维度与全局维度**：IP 限制挡单点脚本，全局限制挡分布式注册。

::: warning 邮箱验证的前提
开启 `register_email_verification` 前先在[邮件配置](/config/settings-email)配好可用的 SMTP，并建议用「测试发信」验证——否则用户收不到验证码将无法完成注册。
:::

## 维护模式

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `maintenance_mode` 启用维护模式 | 关 | 开启后**控制台**显示维护提示横幅（用户仍可登录查看，写操作不受影响） |
| `maintenance_message` 维护提示信息 | 空 | 维护横幅展示的文字，如「系统维护中，预计 30 分钟」 |
| `maintenance_duration` 预计维护时长 | 空 | 展示给用户的预计持续时间，如「2 小时」 |
| `api_maintenance_enabled` 全局 API 维护 | 关 | 开启后**所有 API 代理请求直接返回 503**。与维护模式是两个独立开关，需要完全停服维护时**两个都开** |

界面行为：关闭维护模式开关时会自动清空维护提示信息与预计时长，避免残留过期文案。

::: tip 维护的组合用法
- 只公告不中断：仅开 `maintenance_mode`；
- 计划内停机（数据库迁移等）：两者同开，控制台提示 + API 503 双管齐下；
- 维护结束后记得两开关都关闭。
:::
