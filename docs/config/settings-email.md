# 邮件配置

**管理后台 → 系统设置 → 邮件配置**

系统对外发信的 SMTP 服务器，服务于：注册 / 重置密码的**邮箱验证码**、新设备登录提醒、余额预警等业务通知邮件。

::: warning 与监控告警邮件是两条通道
管理后台「监控告警」给管理员发的告警邮件读取的是 **config.yaml 中的 `email.smtp.*`**（见[运行配置的低频可选配置](/config/config-yaml#email-smtp-监控告警邮件)）。本页 SMTP 只管面向用户的业务邮件——两处都要发信时需分别配置。
:::

## SMTP 连接

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `email_smtp_host` SMTP 服务器 | 空 | 发信服务器地址，如 `smtp.example.com` |
| `email_smtp_port` SMTP 端口 | `587` | 常见：`587`（STARTTLS）、`465`（SSL）、`25`（明文，不推荐） |
| `email_smtp_username` SMTP 用户名 | 空 | 发信账号，通常是邮箱地址 |
| `email_smtp_password` SMTP 密码 | 空 | 敏感字段。国内邮箱（QQ / 163 等）此处填**授权码**而非登录密码 |

## 发件设置

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `email_smtp_from` 发件人地址 | 空 | 格式 `noreply@example.com`，收件人看到的发件人 |
| `email_smtp_tls` 启用 TLS | 开 | 587 / 465 端口建议开启 |

## 常见服务商示例

| 服务商 | Host | Port | 密码填什么 |
|---|---|---|---|
| QQ 邮箱 | `smtp.qq.com` | 587 | 设置中生成的**授权码** |
| 163 邮箱 | `smtp.163.com` | 465 | 客户端**授权密码** |
| 阿里云邮件推送 | `smtpdm.aliyun.com` | 465 | SMTP 密码 |
| 腾讯企业邮 | `smtp.exmail.qq.com` | 465 | 邮箱密码 / 客户端专用密码 |
| Gmail | `smtp.gmail.com` | 587 | 应用专用密码 |

::: tip 验证是否配好
保存后到租户端触发一次「发送验证码」（注册页开启邮箱验证，或忘记密码页），能收到邮件即配置成功；收不到先检查密码是否应为授权码、端口与 TLS 组合是否匹配。
:::
