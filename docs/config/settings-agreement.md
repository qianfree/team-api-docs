# 用户协议

**管理后台 → 系统设置 → 用户协议**

用户协议（服务条款 / 隐私政策）功能的总开关。

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `agreement_enabled` 启用用户协议 | 关 | 开启后，用户登录时需**接受最新版协议**才能继续使用；协议版本的编辑在「运营管理 → 用户协议」页面 |

## 使用流程

1. 在本页打开「启用用户协议」并保存；
2. 前往**运营管理 → 用户协议**，创建并发布协议版本（支持富文本，可随时发布新版）；
3. 发布新版本后，用户下次登录会弹出协议确认，接受后记录接受时间与版本号（满足合规留痕要求）。

::: tip
面向企业客户 / 需要合规留痕（如等保、GDPR）的运营环境建议开启；个人 / 内部使用可保持关闭，减少登录摩擦。
:::
