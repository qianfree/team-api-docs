# 支付配置

**管理后台 → 系统设置 → 支付配置**

租户钱包充值的全局参数：面额、折扣、汇率与文案。

## 基础设置

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `payment_currency` 货币单位 | `CNY` | 充值结算货币，`CNY` / `USD` 二选一 |
| `payment_min_topup` 最低充值金额 | `1` | 单笔充值下限，防止小额手续费亏损 |
| `payment_callback_base_url` 支付回调基础 URL | 空 | 拼接支付平台异步通知地址用；**为空则取请求 Host**。经反向代理 / 多域名部署导致回调地址拼错时，显式填 `https://api.example.com` |

## 货币兑换

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `payment_exchange_rate_cny_to_usd` CNY → USD 兑换比例 | `0.14` | 内部存储 1 人民币 = 多少美元；界面上以 **USD → CNY**（1 美元兑多少人民币，约 7.0–7.3）输入，保存时自动取倒数，确保往返换算闭合 |

::: tip 为什么界面用 USD → CNY
系统内部账本以 USD 计价（模型上游定价是美元），充值多用人民币。界面按「1 美元 = 7.2 人民币」的日常习惯输入，存储层自动换算成 CNY→USD，两个方向换算永远闭合、不会出现汇率缝隙。
:::

## 充值选项

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `payment_amount_options` 充值金额选项 | `[10,20,50,100,200,500]` | JSON 数组：充值页展示的预设面额按钮 |
| `payment_amount_discount` 充值折扣 | `{}` | JSON 对象：`{"100": 0.9}` 表示充 100 实付 90（9 折）；`{"500": 0.85}` 充 500 享 85 折。键为面额（字符串），值为折后比例 |

示例——充值大单促销：

```json
{
  "100": 0.95,
  "200": 0.9,
  "500": 0.85
}
```

::: warning
折扣键需与「充值金额选项」中的面额对应，自定义金额不参与折扣。定价前核算成本，折扣直接减少钱包入账。
:::

## 支付说明

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `payment_notice` 支付说明 | 空 | 展示在租户端**钱包充值页**的说明文案，支持纯文本或 HTML（提示不支持退款、渠道折扣活动等）。纯文本换行用 `<br>` |

例如：

```html
充值一经到账不支持退款，请按需充值。<br>
使用支付宝支付享 <b>95 折</b>；单笔充 500 以上享 85 折。
```
