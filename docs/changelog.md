## v0.2.12

[2026-08-20](https://github.com/qianfree/team-api/releases/tag/0.2.12) · 支持分时价格配置

### ✨ 新特性

#### 🕐 模型时段定价（分时计费）

- 🏷️ 模型价格支持按时段配置乘数：闲时折扣、工作日高峰、限时促销等场景
- 📐 时段为命名有序数组（名称 / 适用日 / 每日时间窗 / 有效期 / 乘数），从上到下先命中先生效，未命中按默认价（乘数 1.0）
- 💸 乘数作用于该模型全部价格：各阶梯档、缓存价、按次价
- ⏱️ 定价时刻 = 请求（任务）受理时刻，异步任务结算同样按受理时刻计价，不受任务完成时间影响
- 🌏 新增「计费时区」系统设置（`pricing_time_timezone`，默认 `Asia/Shanghai`），时段按平台时区解释
- 🏷️ 新增价格展示字段：折扣标签（对外展示，如"7折起"、"限时5折"）、价格调整说明（对外提示，如"9月1日起输入价下调"）、价格备注（仅管理后台可见）
- 🖥️ 管理后台价格设置界面重写（抽屉 → 弹窗），支持时段与展示字段配置
- 🛒 租户端模型广场、模型价格页展示分时价格、折扣标签与调价说明

#### 🔍 渠道调试日志

- 🎛️ 渠道级调试开关，支持按租户 / 成员 / API Key 过滤调试目标，精准复现问题请求
- 📋 开启后按 per-attempt 记录（failover 各自成一条）四段完整报文：客户端请求 → 发往上游请求 → 上游响应 → 返回客户端响应（请求头 / 请求体 / 编码）
- 📏 body 完整记录不截断，另记录协议转换信息（客户端协议 / 上游协议 / 转换链 / 桥接方式）与各段耗时（上游往返 / 首字节 / 总耗时）
- ⚡ 异步批量落库，不影响请求转发性能

#### 📊 渠道模型级监控

- 📈 渠道详情页显示渠道下每个模型的实时运行状态：健康分、成功率 EWMA、延迟 EWMA、熔断状态
- 🎯 重置健康度支持指定模型名单模型重置（留空仍重置整个渠道）
- ✅ 允许对禁用状态的渠道执行手动模型测试，便于启用前确认渠道已恢复
- 🚫 禁用渠道的手动测试不再上报健康分（禁用渠道不在调度目录，上报只会无意义拉低展示值）

### 🐛 Bug 修复

- 🔀 渠道调度：新增模型级熔断分类，404 / 模型不存在 / 模型映射失败只熔断「渠道×该模型」（独立阈值），单个模型异常不再导致整个渠道被熔断拖垮
- 🔐 安全修复：修复大模型代理接口向客户端泄露关键信息的问题——传输层错误信息不再包含上游 URL / IP / 内部错误细节，改为统一的中文化提示
- 🔐 安全修复：租户用量日志改为白名单查询，不再返回上游模型映射、上游账户成本、计费快照等平台侧敏感字段

## v0.2.11

[2026-08-18](https://github.com/qianfree/team-api/releases/tag/0.2.11) · 增加对 Responses 协议的支持

### ✨ 新特性

#### 🤖 OpenAI Responses 协议支持

- 🎯 新增 `/v1/responses` 端点，完整支持 OpenAI Responses API
- 🔧 渠道×模型粒度协议能力标记（`supports_responses` / `chat_via_responses`），同一渠道的不同模型可独立配置协议支持
- ⚡ Responses 入站请求自动直连支持该协议的上游，调度时对这类渠道软偏好
- 🌉 支持 responses-only 上游（如 Codex 类中转）：chat 入站请求自动经 chat→Responses 桥接转换后发送到 `/v1/responses`
- 🔄 Responses ↔ Claude 协议互转：Responses 入站请求可桥接转发至 Claude 协议上游

#### 💰 Claude 缓存计费增强

- 🕐 支持 Claude 模型 5 分钟 / 1 小时 TTL 缓存差异化收费

#### 📊 渠道与缓存监控

- 📈 模型性能监控新增缓存指标：缓存创建 token 数、缓存读取 token 数、缓存命中率
- 🔍 模型性能监控支持按指定渠道筛选查看运行状态

### 🐛 Bug 修复

- 🧮 修复 Gemini 模型思考 token 二次计费的问题
- 🧮 修复各协议转换时缓存 token 数丢失的问题
- 🔌 修复渠道修改 Base URL 后地址不匹配的问题
- ⚖️ 修复渠道权重被设置为 0 的问题
- 🐋 修复 DeepSeek 模型适配器处理 chat 协议的问题
- 🔑 修复在线体验获取到无效 API Key 的问题
- 🔢 修复 token 用量转换的问题
- 📝 修复日志写入遇到特殊字符报错的问题

### 🎨 界面优化

- 🗂️ 统一用户端「API 密钥」与「项目详情」的 API 密钥界面
- 📊 优化管理后台图表显示效果
- 📋 优化管理后台表格显示
- 💡 渠道测试添加提示信息
