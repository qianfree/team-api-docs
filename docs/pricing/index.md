# 授权与定价

> 🚧 本页面建设中，商业授权方案与价格整理中。

## 开源许可

Team-API 基于 **AGPL-3.0** 许可发布，个人与内部使用请遵循[开源协议](https://github.com/qianfree/team-api/blob/main/LICENSE)。

## 商业授权（规划中）

计划提供以下授权类型（具体价格与权益以正式发布为准）：

| 授权类型 | 适用对象 | 说明 |
|---------|---------|------|
| 个人 / 内部使用 | 个人、企业内部 | 遵循 AGPL-3.0 即可免费使用 |
| 商业授权 | 对外提供商业服务 | 免除 AGPL 开源义务 + 官方技术支持 |
| 定制服务 | 有定制需求客户 | 二次开发、私有部署咨询 |
